The problem

Buyers bid over asking. The appraisal decides who pays for it.

  • Low supply → buyers offer over asking to win.
  • Appraises that high → the higher price can be financed (with loan approval).
  • Appraises lower → the buyer brings the difference as additional cash to close.
  • The appraisal arrives after the contract and goes to the lender. The seller may never see it, and its values are never shared publicly.

CT purchases priced above the appraisal: 4.0% in 2019 → 10.3% in 2021 → 9.9% in 2023 (FHFA UAD).

Safety · 9 of 9 live attacks defended
  • Injection: tamper scan + code backstop; input guard on chat
  • Invented facts: grounding guard; a mislabeled "$13,000" caught in the user test → fixed + test
  • Loops / cut-offs: tool-round cap, forced final answer, cut-off detection
  • Overspending: 1,200-token cap, $0.25/session, $2/day, rate limits, kill switch
  • People decide: only a named human closes a review ticket

What's next

Fill the registry, then grow beyond Connecticut

  • Real shared records through housing counselors, CHFA programs, and buyer's agents at closing
  • MCP server so any AI client can answer from the same grounded records
  • More states (FHFA and HMDA are national; the sale check needs state data)
  • Label-aware grounding: check that each number keeps its meaning, not just its value

Limits: registry starts empty (SAMPLE demos only) · FHFA is yearly and hides small tracts · HMDA in $10k bands · one user test so far.
